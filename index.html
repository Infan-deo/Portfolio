Solo Project Completed PERSONAL · 02
Bombtag

A solo-built multiplayer party game where players pass a live bomb to another player before the timer runs out. Built from scratch with FishNet networking and deployed on Linux dedicated servers through Edgegap.

What I built
  • Client-side prediction for responsive player movement with server reconciliation
  • Create and join room system for multiplayer matches
  • Steam integration using Facepunch Steamworks to identify players by their Steam profile and display Steam names
  • Steam profile data synchronization across multiplayer clients
  • Server-authoritative gameplay running on a dedicated Linux server
  • Multi-room multiplayer architecture for running separate matches concurrently
  • Core Bombtag gameplay loop — passing the bomb before the timer expires
